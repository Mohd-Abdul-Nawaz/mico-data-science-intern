## PROJECTS

### 1. E-Commerce Customer Purchase Behavior Analysis — Exploratory Data Analysis
**Python | Pandas | NumPy | SciPy | Matplotlib | Seaborn | Jupyter Notebook**

- Performed end-to-end exploratory data analysis on a 2,010-row e-commerce customer dataset covering demographics, membership tiers, purchase behaviour and satisfaction scores.
- Handled missing values (median for numerical, mode for categorical), removed duplicate rows, and detected outliers in `Purchase_Amount` using the IQR method.
- Applied ANOVA hypothesis testing to compare purchase amount across membership tiers (F = 18.70, p < 0.001), confirming a statistically significant difference, and computed Pearson correlation (Age vs. Purchase Amount = 0.050).
- Engineered Boolean and categorical features (high spender flag, age-group bins, recent-customer flag) and produced correlation heatmaps and distribution visualisations.

### 2. House Price Prediction — Multiple Linear Regression
**Python | Scikit-learn | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook**

- Built a Simple and Multiple Linear Regression model on 1,494 preprocessed housing records, treating missing values by median imputation and capping price outliers via the IQR method.
- Applied a `ColumnTransformer` pipeline combining `StandardScaler` for numerical features and `OneHotEncoder` for the `Location` categorical variable.
- Achieved **R² = 0.866** and **Adjusted R² = 0.863** on the held-out test set, with MAE ₹3.45L and RMSE ₹4.42L.
- Computed Adjusted R² using the post-encoding feature count, validated regression assumptions through residual analysis, and interpreted coefficients to explain key price drivers.

### 3. Customer Churn Prediction — Logistic Regression with SMOTE
**Python | Scikit-learn | Imbalanced-learn | Pandas | Seaborn | Jupyter Notebook**

- Developed a Logistic Regression classifier on 3,000 subscription records to predict customer churn (34.6% positive class, addressing a clear class-imbalance problem).
- Built an `imbalanced-learn` pipeline that applies `StandardScaler`/`OneHotEncoder` **before** `SMOTE`, so oversampling acts only on encoded numeric features and no data leakage occurs from the test split.
- Evaluated with a confusion matrix, precision/recall/F1 report and ROC-AUC (**0.684**), with churn-class recall of 0.68 versus 0.61 for the retained class.
- Documented the preprocessing order, resampling rationale and trade-offs between precision and recall for retention campaigns.
