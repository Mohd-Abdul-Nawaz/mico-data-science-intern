## Quick start

Requires **Python 3.11** (recommended — `runtime.txt` and `.python-version` pin it; the bounded `requirements.txt` also installs from prebuilt wheels on 3.12/3.13).

```bash
git clone https://github.com/Mohd-Abdul-Nawaz/mico-data-science-intern.git
cd mico-data-science-intern
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt    # from the repo ROOT — this is what Streamlit Cloud installs
```

The three datasets are committed, so validation works immediately:

```bash
cd Mico_Data_Science_Projects
python generate_data.py            # optional: regenerate the three CSVs (already committed)
python _run_all.py                 # runs all three analyses -> RESULT: 3/3 scripts succeeded
python _verify_apps.py             # headless smoke test    -> SUMMARY: 3/3 apps passed
```

Launch a dashboard:

```bash
python -m streamlit run project_1_eda_customer_behavior/streamlit_app.py
python -m streamlit run project_2_regression_house_prices/streamlit_app.py
python -m streamlit run project_3_classification_churn/streamlit_app.py
```

## Reproducibility

- Data is **synthetic**, generated by `generate_data.py` — no external downloads needed.
- Every model uses `random_state=42`, so the metrics above reproduce exactly.
- Validated locally on **Python 3.11** (numpy 2.2.6, pandas 2.3.3, scikit-learn 1.7.2, streamlit 1.49.1): `_run_all.py` → 3/3, `_verify_apps.py` → 3/3.

## Deployment

The three dashboards run on **Streamlit Community Cloud** from this repo's `main` branch.

See [`Mico_Data_Science_Projects/DEPLOYMENT_GUIDE.md`](./Mico_Data_Science_Projects/DEPLOYMENT_GUIDE.md) for the full walkthrough — including why `requirements.txt` uses bounded ranges instead of exact pins (exact pins have no wheels for Python ≥ 3.13, which makes the cloud build hang while pip compiles from source).
